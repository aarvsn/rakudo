Dumping your own BIOS and firmware

Where an emulator needs a BIOS or firmware file, it must come from hardware you legally own. This section describes the general method for each generation without linking to or naming any pre-dumped file repositories.

§B.1PS1 / PS2 BIOS extraction

Both are typically dumped using a modchip or soft-modding exploit (e.g. a FreePSXBoot-class exploit for PS1, or a homebrew-enabled memory card exploit for PS2) that lets you run a small dumper executable on the real console, reading the BIOS ROM out to a memory card or USB storage device. The resulting file is your own copy, tied to your own console's region.

§B.2PS3 firmware

Unlike PS1/PS2, RPCS3 uses Sony's official, freely redistributable firmware updater package directly from Sony's own servers — no console or dumping required. The emulator's own first-run setup wizard downloads and installs it automatically.

§B.3PS Vita firmware modules

Vita3K's optional firmware files must be extracted from a Vita you own, after enabling homebrew access (commonly via the HENkaku/h-encore family of exploits, which do not require any hardware modification), using a dedicated dumper homebrew application.

A note on sourcing files online: downloading a BIOS, firmware image, or ROM dumped by someone else — rather than by you, from hardware you own — is a copyright infringement in most jurisdictions regardless of whether the original console is still sold. Dumping tools exist specifically so this is unnecessary.
