Generation 2 · Codename "Emotion Engine"

PlayStation 2

SCPH-10000 → SCPH-9000x

Launched in Japan on 4 March 2000, the PS2 remains the best-selling console of all time at roughly 160 million units sold. Its defining trait is a split, highly parallel architecture built around two custom Sony/Toshiba processors — the Emotion Engine and the Graphics Synthesizer — designed for brute-force vector throughput rather than general-purpose flexibility, which is the root cause of most of the platform's emulation difficulty.

§2.1Core architecture

CPU"Emotion Engine" — custom 128-bit MIPS III/IV-based core at 294.912 MHz (299 MHz on later revisions), with two integrated vector units (VU0 tightly coupled as a coprocessor, VU1 loosely coupled with its own 16 KB micro-instruction memory) plus an on-die IPU (Image Processing Unit, MPEG-2 decode for DVD video).
Vector UnitsVU0 + VU1: superscalar FPU-based DSPs used for geometry transform, skinning, and particle simulation; combined the EE was rated at a peak 6.2 GFLOPS.
GPU"Graphics Synthesizer" (GS) — custom rasterizer at 147.456 MHz, fixed-function (no programmable shaders), 2560-bit-wide internal bus to its own embedded memory, no texture compression support (a frequent cause of the PS2's blurry/aliased look versus contemporaries).
eDRAM4 MB embedded DRAM on the GS die itself, holding framebuffer + Z-buffer + textures simultaneously — the small pool forces frequent texture-cache thrashing, a major emulation performance bottleneck.
Main RAM32 MB Direct RDRAM, 400 MHz bus (3.2 GB/s bandwidth to the EE).
Sound"SPU2" custom chip, 48 hardware voices, 2 MB dedicated sound RAM, ADPCM + PCM playback.
I/O ProcessorA full PS1 CPU (R3000A) repurposed as the IOP, handling controller/memory-card I/O, CD/DVD access and — critically — providing full hardware-level PS1 backward compatibility.
Optical driveDVD-ROM (4x), also reads CD-ROM for PS1 titles; region-coded via disc + BIOS check.
OutputComposite, S-Video, RGB SCART, component (progressive scan support added via firmware from launch on supporting titles), no native HDMI on any revision.
Storage expansionInternal 3.5" IDE HDD bay (SCPH-10000/30000 series, via the Network Adaptor add-on) supporting select online titles and the "HDD Boot" homebrew ecosystem.
Process node180 nm EE+GS at launch; both cores were eventually merged onto a single 90 nm die ("EE+GS") in the SCPH-7000x slim revisions, drastically cutting cost and power draw.

§2.2Notable model variants

SCPH-10000 / 15000 (JP, 2000)

Launch "fat" units

i.LINK (FireWire) port present, dropped from most later fat revisions.

SCPH-3900x (2002)

PSTwo prototype-adjacent revision

Widely considered the most reliable fat motherboard for laser longevity.

SCPH-7000x "Slim" (2004)

Single-chip EE+GS

~40% smaller, no HDD bay, built-in Ethernet, external power brick, top-loading slot drive.

SCPH-9000x (2007, final revision)

Last production run

Refined power supply, produced until PS2 manufacturing ended in December 2012 in Japan — the longest production run of any Sony console.

§2.3Emulation guide

RECOMMENDED
PCSX2 — effectively the only actively developed, viable PS2 emulator; no meaningful competitor exists as of 2026.
ACCURACY
HIGH — the vast majority of the ~4,000-title library runs correctly; the harder-to-emulate outliers are almost always titles that rely on exact VU1 microcode timing or exotic GS blending tricks.
BIOS REQUIRED
Yes, always. PCSX2 has no HLE BIOS mode — you must dump the BIOS from your own console (region-matched to your game discs) before the emulator will boot anything.
HOST REQUIREMENT
Modern 4+ core CPU with strong single-thread performance (PCSX2's EE core recompiler is largely single-threaded); a discrete GPU is recommended once internal resolution is pushed above native for the GS software fallback paths some titles require.
RENDERER
Vulkan is the current recommended graphics backend for both performance and correctness; the legacy OpenGL/D3D11 backends remain for compatibility fallback.
KNOWN ISSUES
A small set of titles exhibit GS "texture bleeding" or z-fighting due to the software-rounding differences versus the eDRAM's exact behaviour; a handful of PS1 BC titles played through the PS2 IOP path have separate compatibility quirks from native PS1 emulators.
