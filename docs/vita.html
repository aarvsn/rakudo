PlayStation Vita

PCH-1000 → PCH-2000

Launched in Japan on 17 December 2011, the Vita packed console-class hardware — a quad-core ARM Cortex-A9 and a quad-core PowerVR GPU — into a handheld with dual analog sticks and a capacitive OLED touchscreen, but was commercially undercut by the rapid rise of smartphone gaming and Sony's own decision to restrict third-party game-card manufacturing to a proprietary format.

§5.1Core architecture

CPUARM Cortex-A9 MPCore, 4 cores (quad-core, though one core is typically reserved by the OS for background tasks), clocked at ~444 MHz active per-game (silicon capable of higher clocks, deliberately underclocked by Sony for thermal/battery reasons).
GPUPowerVR SGX543MP4+, 4 cores, ~166–222 MHz, supporting OpenGL ES 2.0-class programmable shaders — a generational leap in flexibility over the PSP's fixed-function GE.
Main RAM512 MB LPDDR2.
VRAM128 MB dedicated, plus the GPU can also access system RAM.
DisplayPCH-1000: 5" OLED, 960×544. PCH-2000 "Slim": 5" LCD (cost-reduced, marginally worse black levels but better outdoor visibility and battery life).
Storage mediaProprietary Vita Game Card (up to 4 GB) for retail games; proprietary Sony Memory Card (not standard microSD) required for saves/digital purchases — a widely criticised design decision that raised long-term running costs.
SensorsRear touchpad (a Vita-exclusive input method), front capacitive touchscreen, three-axis accelerometer and gyroscope, GPS (Wi-Fi/3G model only), digital compass.
Connectivity802.11b/g/n Wi-Fi on all models; 3G data (PCH-1100 / 1180x) on the cellular SKU, since discontinued at the carrier level.

§5.2Notable model variants

PCH-1000 (2011/2012)

Launch OLED model

Wi-Fi and Wi-Fi+3G SKUs; highest-quality display of any Vita revision.

PCH-2000 "Slim" (2013)

LCD redesign

~20% lighter, ~4x internal flash storage over the original, micro-USB charging (vs. proprietary connector), no rear touchpad on the PS TV variant.

PlayStation TV / VTE-1000 (2013)

Micro-console derivative

Vita hardware in a set-top-box form factor for TV output; no built-in screen, touchscreen, or rear touchpad, limiting compatible software.

§5.3Emulation guide

RECOMMENDED
Vita3K — the only meaningful open-source Vita emulator project, in active development since 2018.
ACCURACY
PARTIAL — a substantial and growing portion of the commercial library is playable, but compatibility is inconsistent title-to-title; this remains one of the least mature major-platform emulation projects due to the size and complexity of the Vita's system software stack.
FIRMWARE REQUIRED
No BIOS dump, but Vita3K requires Vita system firmware files extracted from a legitimately owned and jailbroken/hacked Vita console to supply certain system modules for some titles; a growing subset of games run without any firmware files via Vita3K's HLE modules.
HOST REQUIREMENT
Moderate — a mid-range 2020s CPU and a Vulkan-capable GPU are recommended; performance varies significantly by title given the JIT-recompiled ARM core.
KNOWN ISSUES
Touch/rear-touchpad-dependent titles need manual control remapping; some titles crash or have broken shaders due to incomplete GXM (the Vita's low-level graphics API) reimplementation.
