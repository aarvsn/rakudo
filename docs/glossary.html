Glossary

HLEHigh-Level Emulation — reimplementing what a system call or library does in the emulator's own code, rather than running the original binary that does it. Faster and doesn't require original firmware, but only as accurate as the reimplementation.
LLELow-Level Emulation — running the console's own original firmware/BIOS code on emulated hardware. Slower, and requires a legitimately dumped firmware file, but inherits the original's exact behaviour.
Recompiler / JITA technique that translates a console's native CPU instructions into the host PC's instructions on the fly, rather than interpreting them one at a time — the main reason modern emulators can run console code faster than the original hardware.
eDRAMEmbedded DRAM placed directly on a processor die for very high bandwidth to a small memory pool, as used by the PS2 Graphics Synthesizer.
GTE / VU / SPEGeneration-specific names for the PlayStation line's dedicated vector-math coprocessors: Geometry Transformation Engine (PS1), Vector Unit (PS2), Synergistic Processing Element (PS3 Cell).
Checkerboard renderingA technique used by the PS4 Pro (and later refined via other means on PS5 Pro) to render alternating pixels at full and half resolution, then reconstruct a full-resolution image, as a cheaper alternative to native 4K rendering.
