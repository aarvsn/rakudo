Generation 1 · Codename "PS-X" / Net Yaroze for developers

PlayStation

SCPH-1000 → SCPH-9000

Released in Japan on 3 December 1994, the PlayStation was Sony Computer Entertainment's first console and the first CD-ROM-based platform to sell past 100 million units. It replaced sprite-based 2D hardware with a dedicated 3D geometry engine, the first mainstream console to do so, and it shipped a CD-ROM drive as standard at a time most competitors still used cartridges.

§1.1Core architecture

CPULSI CoreWare CW33300 — a custom MIPS R3000A-compatible 32-bit RISC core, 33.8688 MHz, with an integrated GTE (Geometry Transformation Engine) and MDEC (Motion Decoder) coprocessor on-die.
GTE (geometry)Fixed-function coprocessor 2 (COP2), performs perspective transform, lighting and matrix math; rated ~66 MIPS, capable of roughly 360,000 flat-shaded polygons/sec in ideal conditions (real-world output typically 90k–180k due to CPU issue bandwidth).
GPUCustom Sony 2D/3D rasterizer, no dedicated frame buffer chip separate from VRAM; renders flat and Gouraud-shaded, textured or untextured polygons and quads. No native Z-buffer — developers use manual polygon sorting (painter's algorithm) via the Ordering Table.
Video RAM1 MB dedicated VRAM (framebuffer + texture cache + CLUTs share this pool).
Main RAM2 MB EDO DRAM, 32-bit bus.
Sound RAM512 KB, feeds the SPU.
SPU (audio)Sony custom ADPCM sound processor, 24 hardware voices, 44.1 kHz output, reverb and pitch-modulation built in.
MDECHardware motion-JPEG-style decompressor used for FMV playback (Bink/Smacke-style pre-rendered video was not used; PS1 FMV is MDEC-decoded).
Optical driveSingle-speed (2x from SCPH-5500 onward) CD-ROM, reads standard Yellow Book CD-ROM plus the proprietary "wobble groove" region/anti-piracy encoding on the disc's lead-in.
OutputComposite video, RF (early NTSC-J units), S-Video, and RGB SCART (PAL/JP); no digital output. Native resolution 256×224 up to 640×480 interlaced, typically 320×240.
Controller portProprietary 7-pin serial bus, 2 controller ports + 2 memory card slots; supports Dual Analog / DualShock controllers via the same protocol from 1997 onward.
Memory Card128 KB flash card, 15 usable blocks of 8 KB each (FAT-like block allocation table).
Process node0.35 µm at launch, die-shrunk to 0.25 µm and eventually integrated into the single-chip "PS-One" SoC (CXD8945Q) by 2000.

§1.2Notable model variants

SCPH-1000 / 1001 (JP/US, 1994–95)

Launch unit

Parallel I/O port on rear for peripherals (Net Yaroze link cable, GameShark). Digital output header present but unused by retail units.

SCPH-5500 / 5501 / 5502 (1997)

DualShock-era revision

Removed the S-Video port on some regions, bundled with the original DualShock controller (SCPH-1200).

SCPH-7000 series (1998–2000)

Cost-reduced board

Parallel port removed; smaller motherboard, single main ASIC integrating more logic.

SCPH-100 "PS-One" (2000)

Redesigned SoC

~45% smaller footprint, optional LCD screen accessory (SCPH-130), single-chip CXD8945Q, external power brick.

§1.3Emulation guide

RECOMMENDED
DuckStation for gameplay accuracy and speed; pcsx-redux for development/debugging work; Beetle PSX HW (via RetroArch) for enhanced internal resolution with hardware accuracy.
ACCURACY
FULL — the PS1's CPU and GPU pipeline are fully reverse-engineered and documented (psx-spx); commercial library compatibility exceeds 99%.
BIOS REQUIRED
Yes. A legally dumped copy of your own console's BIOS ROM (512 KB, e.g. SCPH1001.BIN) is required for full compatibility; DuckStation ships an optional open-source HLE BIOS fallback with reduced compatibility.
HOST REQUIREMENT
Negligible by 2026 standards — any x86_64 or ARM64 device from the last decade, including phones, runs PS1 titles at full speed with headroom for upscaling.
UPSCALING
Internal resolution can be raised well past the native 320×240 via the hardware (Vulkan/D3D12/OpenGL) renderers; PGXP (Precision Geometry Transform Pipeline) corrects the console's signature vertex-jitter and texture warping caused by its lack of a floating-point GTE.
KNOWN ISSUES
A minority of titles rely on exact GPU timing quirks (e.g. specific loading-screen behaviour) that can differ subtly between emulators and real hardware; CD read-speed emulation affects a handful of FMV-heavy titles.
