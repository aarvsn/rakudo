Generation 4 · x86-64 unification

PlayStation 4

CUH-1000 → CUH-7200 (Pro)

Launched in North America on 15 November 2013, the PS4 abandoned PlayStation's tradition of exotic, hard-to-program custom silicon in favour of a semi-custom AMD APU built on standard x86-64 (Jaguar) CPU cores and a GCN-architecture GPU — the same broad architecture family used in contemporary Windows PCs — which made third-party development dramatically easier and, eventually, made emulation development more approachable than any prior generation.

§6.1Core architecture

APUSemi-custom AMD "Liverpool" — 8-core AMD Jaguar CPU (two clusters of 4 cores) at 1.6 GHz, paired on-die with a GCN 1.1 (Radeon-class) GPU.
GPU1152 shader cores (18 compute units), 800 MHz, ~1.84 TFLOPS single-precision; PS4 Pro raises this to 2304 shader cores (36 CUs) at 911 MHz, ~4.2 TFLOPS.
System memory8 GB GDDR5 unified pool shared between CPU and GPU, 176 GB/s bandwidth (base); PS4 Pro retains 8 GB GDDR5 at 218 GB/s.
Storage2.5" SATA HDD (500 GB base at launch, up to 1 TB on later SKUs and the Pro), user-replaceable; supports user-installed SSDs though the SATA II interface caps real-world gains.
Optical driveBlu-ray (6x BD-ROM), DVD playback; no 4K UHD Blu-ray support on any PS4 model.
OutputHDMI 1.4 (base), HDMI 2.0b (Pro/Slim, enabling native 4K output and HDR); base PS4 outputs up to 1080p, Pro supports checkerboard/dynamic-resolution "4K" rendering.
Backward compatibilityNone at the hardware or native-emulation level; select PS1/PS2/PS3 titles were made available only via Sony's since-discontinued "PS Now"-style cloud-streaming service, not local emulation.
Process node28 nm at launch (base + original Pro), later revisions of the base model (CUH-2000 "Slim") shrunk to a more efficient 16 nm process for reduced power draw and heat.

§6.2Notable model variants

CUH-1000 (2013)

Launch model

28 nm APU, prone to a higher failure rate on early manufacturing runs than later revisions; optical audio-out present (removed on Slim).

CUH-2000 "Slim" (2016)

Cost/size reduction

16 nm APU, ~11 mm thinner, matte finish, USB-C-shaped (but USB 2.0 spec) port added on later revisions.

CUH-7000 "Pro" (2016)

Mid-gen performance refresh

Doubled GPU compute units, boost-mode CPU clock, no native 4K Blu-ray or disc-drive changes; first console in the line to explicitly target checkerboard 4K rendering rather than native resolution increases.

§6.3Emulation guide

RECOMMENDED
shadPS4 — the leading open-source PS4 emulation project as of 2026; a small number of alternative/derivative forks exist but track shadPS4's core progress closely.
ACCURACY
EARLY — PS4 emulation is significantly younger and less mature than PS1–PS3 emulation. A meaningful and growing subset of the 2D and lighter 3D library boots and is playable; demanding AAA titles remain unreliable or unplayable. Treat this generation as an actively moving target rather than a solved platform.
FIRMWARE REQUIRED
No BIOS/firmware dump is required — shadPS4 reimplements the PS4's system libraries (a "libSceX" HLE approach similar in philosophy to PPSSPP) rather than running Sony's own firmware.
HOST REQUIREMENT
High-end 2023-or-later x86-64 CPU with strong single/few-thread performance and a modern GPU with mature Vulkan drivers; given the Jaguar CPU's low per-core clock, most modern desktop CPUs already exceed it several times over, so the GPU shader-translation and system-call-emulation layers are the current bottleneck rather than raw compute.
KNOWN ISSUES
Frequent title-specific crashes, missing audio, and shader-compilation stutter are expected at this stage of the project's maturity; check the emulator's own compatibility tracker before assuming any specific title is playable.
