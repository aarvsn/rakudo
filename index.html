Rakudo
楽土

A single-file, offline-readable reference for the hardware inside every PlayStation console, and a practical guide to emulating each of them on modern PCs.

Rakudo (楽土 — "land of comfort") documents the architecture of the PlayStation, PS2, PSP, PS3, PS Vita, PS4, PS VR / VR2 and PS5 families: die-level components, memory subsystems, storage media, model revisions by region, and the current state of software emulation for each platform. It is written for people who already own the hardware they intend to preserve or emulate, and who want primary-source-accurate numbers instead of marketing copy.

§How to read this book

Each console generation follows the same structure: a hardware overview, a full component-level specification table, the notable regional/model variants, and an emulation guide with the current best-in-class emulator, its accuracy status, minimum host requirements, and configuration notes. Specification figures are sourced from Sony technical documentation, official service manuals, teardown reports, and long-standing homebrew/reverse-engineering documentation (No$psx, PSDevWiki, psx-spx, Vita Nubis, RPCS3 wiki). Where a figure is disputed or was never officially confirmed (marked UNCONFIRMED), it is labelled as such rather than presented as fact.

Emulator accuracy statuses used throughout: FULL nearly all commercial software runs correctly, HIGH the large majority runs correctly with minor issues, PARTIAL playable but with known regressions, EARLY boots a limited library, experimental.
